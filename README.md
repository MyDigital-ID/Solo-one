# 👔 SOLO SUITS

موقع وتطبيق **Solo Suits** — من أفضل برندات بيوت الأزياء العالمية في مصر (الإسكندرية).

**الموقع:** https://mydigital-id.github.io/solo-suits/
**لوحة التحكم:** https://mydigital-id.github.io/solo-suits/admin.html

---

## 📁 هيكل المشروع

```
Solo-suits/
├── index.html            الصفحة الرئيسية + الـ SEO (Open Graph / Schema)
├── style.css             التصميم
├── script.js             منطق الموقع (الأقسام، السلة، الفيديو الافتتاحي، اللمس)
├── site-data-loader.js   تحميل site-data.json (الشبكة أولاً، وبعدها آخر نسخة محفوظة)
├── service-worker.js     العمل بدون إنترنت (غيّر رقم VERSION لما ترفع تعديلات)
├── site-data.json        الأقسام والمنتجات والإعدادات (بتتعدل من لوحة التحكم)
├── admin.html / admin.js لوحة التحكم (بتحفظ مباشرة في GitHub)
├── manifest.json         إعدادات تثبيت التطبيق (PWA)
├── robots.txt / sitemap.xml
└── assets/
    ├── images/           الصور والأيقونات والفيديو الافتتاحي (splash.mp4)
    └── uploads/          الصور اللي بترفعها من لوحة التحكم
```

## 🌟 المميزات

- تصميم سينمائي (خلفية رمادية) مع عرض Coverflow للأقسام
- 8 أقسام: بدل، رجالي، نسائي، بلاطي، كرافتات، أحذية جلد طبيعي، أحزمة جلد طبيعي، ملابس أطفال
- فيديو افتتاحي مع زرار كتم/تشغيل الصوت
- حماية من اللمس العفوي (السكرول أو اللمسة الخفيفة مش بتفتح قسم)
- سلة وإتمام الطلب عبر واتساب
- يعمل بدون إنترنت (PWA)

## 🔄 بعد كل رفع تعديلات

غيّر رقم `VERSION` في أول `service-worker.js` (مثلاً `solo-shell-v1.0.1` ← `solo-shell-v1.0.2`) عشان الأجهزة تحمّل النسخة الجديدة.
